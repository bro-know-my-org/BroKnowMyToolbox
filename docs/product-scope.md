# 产品范围

## 产品目标

Bro Know My Toolbox 是面向个人用户、普通桌面用户和贡献者的跨平台工具产品。桌面应用提供发现、配置和交互体验，`bkmt` 为人类与自动化环境提供同等的一等入口。

首版必须证明三件事：内置工具易于加入、同一业务行为可以被 GUI/CLI 复用、三平台产物能够构建并启动。

## 首版工具

### 文件生成器

- 支持内置模板和便携数据目录中的用户模板。
- 支持变量替换、多个文件和目录的批量生成。
- 写入前产生生成计划；GUI 默认展示，CLI 提供 `--dry-run`。
- 默认拒绝覆盖；交互确认或 `--force` 才能覆盖。
- 执行结果逐文件报告成功或失败，不把部分成功呈现为完全成功。

### Spark Analyzer

- GUI 集成 `@bro-know-my/spark-analyzer` 的修复版本；发布前本地验证允许使用 sibling file 依赖，正式 Toolbox release 必须固定到已发布版本。
- 原生端集成 `bkmsa-tauri`，CLI 复用 `bkmsa-core` 和 `bkmsa-agent`。
- Toolbox 负责宿主导航、主题、权限、配置路径和错误呈现；Spark 项目拥有分析逻辑。

## 产品能力

- 首页工具发现、全局搜索/命令面板、收藏和最近使用。
- 浅色、深色、跟随系统、强调色、字号和密度设置。
- 内置中英文；用户语言包可覆盖部分稳定键。
- 命令面板支持快捷键、方向键和 Enter 导航；标准控件提供语义标签、可见焦点、合理对比度和减少动画。
- 应用内版本检查和点击下载，不静默替换程序。

## 首版非目标

- 运行时插件安装、插件市场、远程模板安装和第三方代码沙箱。
- 剪贴板管理；旧实现只是能力测试，不构成迁移义务。
- 遥测和崩溃报告。
- 静默或强制自动更新。
- 从旧应用标识或旧 `localStorage` 迁移数据。
- 声称已完成 macOS 公证、Gatekeeper 或真实设备交互验证。

## 首版完成条件

只有同时满足以下条件，首版才算完成：

1. 两个工具在 GUI 和 `bkmt` 中完成约定行为。
2. 产品导航、视觉设置、国际化、权限和数据目录形成完整体验。
3. 单元、接口集成、GUI 关键流程和三平台启动冒烟检查通过；当前仓库只提供本地测试证据，三平台证据必须由发布 CI 补齐。
4. Windows、Linux、macOS 产出可下载的未签名包；CPU 架构以已验证 CI 矩阵为准。
5. GitHub Releases、Scoop、Homebrew Tap 和 AUR 发布流程有可执行实现。
6. README、架构、工具开发、CLI、安全、测试发布和 ADR 与实现一致。
